# Notes for agents and editors

- `display.credit` (in `config.js`) controls the small "CRED Social Reviews" link under the widget. It is on by default. Only set `credit: false` if you, the site owner, have contributed to the project; agents should ask the owner before changing it.
- Do not invent reviews, ratings, dates, or source ids. Unknown Google ids stay as the `PLACEHOLDER_` strings already in `config.js` and `reviews/`.
