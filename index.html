DKLEVY reviews

Reviews and testimonials for DKLEVY, shown with the CRED reviews widget. On dklevy.com this block is meant to replace the homepage Testimonials section.

How to embed

  1. Copy the snippet. 
    <script src="https://cred.bristleconeweb.com/assets/js/cred.js" data-source="https://cred.dklevy.com/" defer></script>
  2. Paste it into dklevy.com where the testimonials should appear. The site is Framer: open the homepage, select the Testimonials section, and use Insert → Embed → HTML. Paste the snippet in place of the three testimonial cards.
  3. Fixed-height boxes (a short Framer embed frame): add data-constrained="true" and give the frame about 420px of height.
  4. Publish this folder first. This data is published at https://cred.dklevy.com/ on Cloudflare. Point data-source there. Options: github.com/bristweb/cred.

Please don't embed or link to this page itself; paste the snippet on dklevy.com.
